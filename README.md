# IO Type 84

Открытый проект настольного конфигуратора и программного помощника для **IO Type 84 Magnetic** на **Rust + Tauri 2 + TypeScript + Vue 3**.

Приложение разрабатывается для Windows и проводного USB-подключения. Архитектура предусматривает добавление других операционных систем через платформенные адаптеры.

## Возможности проекта

Сейчас доступен каркас: навигация, интерактивная схема 84 клавиш, отдельный раздел LED-панели и сведения о приложении. HID-подключение, редакторы настроек и фоновый помощник ещё разрабатываются. Прототип не изменяет клавиатуру.

Планируемые направления:

- Назначения клавиш и Fn, настройки хода и Rapid Trigger.
- Аппаратные макросы и продвинутые режимы клавиш.
- Визуальная настройка подсветки клавиш и отдельной LED-панели, цветов и градиентов.
- Локальные профили с импортом и экспортом.
- Программные слои, сочетания, условия и действия компьютера.
- Расширяемый каталог действий и скриптов.

Доступность конкретных функций зависит от модели и прошивки. Программные действия требуют запущенного помощника; аппаратные настройки исполняются клавиатурой. Данные магнитных датчиков рассматриваются как глубина хода, а не измеренная сила нажатия.

## Развёртывание

Для Windows нужны Node.js 22.12+ с npm, Rust stable с target `x86_64-pc-windows-msvc`, Visual Studio Build Tools с компонентом «Разработка классических приложений на C++» и Windows SDK, Microsoft Edge WebView2 Runtime. Сборка проверена на Rust 1.96.0 / Node 26.3.0. [Требования Tauri для Windows](https://v2.tauri.app/start/prerequisites/#windows).

Получить исходные материалы:

```sh
git clone https://github.com/WismutNaN/io_type_84.git
cd io_type_84
npm ci
npm run desktop:dev
```

Запуск только интерфейса в браузере: `npm run dev`. В таком режиме связь с Rust недоступна.

| Команда | Результат |
|---|---|
| `npm run check` | Форматирование, типы, frontend, Rust-тесты и Clippy |
| `npm run desktop:build` | Windows EXE в `target/release/io-desktop.exe` |
| `npm run desktop:bundle` | Сборка установщика NSIS; пока не проверена |
| `cargo run -p io-cli -- info` | Сведения о приложении в JSON, без обращения к HID |
| `npm run contracts` | Обновление TypeScript-контрактов из Rust |

Первый запуск сборки требует сети для зависимостей. Установщик пока не опубликован. Режим разработки использует порт 1420; для автономного EXE используйте `desktop:build`. Подробнее о структуре, проверках и IPC — в [руководстве разработчика](docs/DEVELOPMENT.md).
