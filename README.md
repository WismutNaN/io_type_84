# IO Type 84

Открытое настольное приложение для настройки **IO Type 84 Magnetic White**. Rust, Tauri 2, TypeScript и Vue 3. Первая поддерживаемая конфигурация — Windows и проводное USB-подключение, прошивка 1.17.

## Возможности

- Раскладка из 84 клавиш, выбор одной клавиши или группы, базовый и Fn-слой.
- Назначения клавиатуры, мыши, мультимедиа, сочетаний и штатных действий прошивки.
- Точка активации и Rapid Trigger; редакторы MT, TGL, RS, SOCD и DKS.
- Аппаратные эффекты, индивидуальные цвета и пространственные градиенты.
- Аппаратные макросы с задержками и записью клавиатуры в окне приложения.
- Локальные профили, импорт/экспорт JSON, частичный импорт IO Vision.
- Черновик с отменой/возвратом, проверка перед применением, резервный снимок и сверка чтением.
- Экспериментальный монитор хода с последними 20 событиями в памяти.

Приложение находится в активной разработке. Проверены чтение и обратимая запись основных блоков конфигурации. Физическое исполнение всех продвинутых режимов и сохранение после отключения питания ещё проходят проверку. Магнитные данные описывают ход клавиши, а не измеренную силу нажатия.

Текущий RGB устройства пока не подтверждён; интерфейс показывает заданные цвета отдельно от измерений. Для LED-панели доступны назначения известных штатных действий; редактор её отдельных цветов и анимаций ещё разрабатывается. Макросы временно ограничены 512 байтами вместе с каталогом. Программные слои, скрипты, фоновый помощник и прошивальщик пока не входят в приложение.

## Развёртывание

Нужны Node.js 22.12+ с npm, Rust stable с target `x86_64-pc-windows-msvc`, Visual Studio Build Tools с компонентом «Разработка классических приложений на C++» и Windows SDK, Microsoft Edge WebView2 Runtime. Сборка проверена на Rust 1.96.0 и Node 26.3.0. [Требования Tauri](https://v2.tauri.app/start/prerequisites/#windows).

```sh
git clone https://github.com/WismutNaN/io_type_84.git
cd io_type_84
npm ci
npm run desktop:dev
```

| Команда | Результат |
|---|---|
| `npm run dev` | Предпросмотр интерфейса в браузере, без USB |
| `npm run check` | Формат, типы, сборка, TS/Rust-тесты и Clippy |
| `npm run desktop:build` | Автономный EXE `target/release/io-desktop.exe` |
| `npm run desktop:bundle` | Установщик NSIS; ещё не проверен |
| `cargo run -p io-cli -- snapshot` | Чтение конфигурации по USB в JSON |
| `cargo run -p io-cli -- monitor 20` | Ограниченный 20 секундами монитор |
| `npm run contracts` | Генерация TypeScript-контрактов из Rust |

Первичная сборка загружает зависимости. Для автономного EXE используйте `desktop:build`: приложение включает локальные ресурсы и не требует Vite. Режим разработки занимает порт 1420. Готовый установщик пока не опубликован.

## Использование

Подключите IO White по USB, закройте другие конфигураторы и нажмите «Подключить клавиатуру». Изменения добавляются в черновик. «Проверить и применить» показывает затронутые блоки, сохраняет резервный снимок и сверяет результат чтением. Сохранение профиля на компьютере само по себе не изменяет устройство.

Профили хранятся локально; для переноса используйте экспорт JSON. Восстановление последней аппаратной операции находится в «Параметрах». История движения клавиш хранится только в памяти текущего сеанса. Неизвестные поля импорта IO Vision пропускаются с отчётом.
