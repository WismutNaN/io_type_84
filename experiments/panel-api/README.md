# Прототип API LED-полосы

Изолированная Rust-библиотека для временной передачи десяти цветов из приложения
в предполагаемое расширение IO Type 84 Magnetic White 1.17. Содержит кодирование
пакетов, проверку ответов и автомат временного владения полосой. Работает без ОС,
динамической памяти и внешних зависимостей (`no_std`).

Это исполняемая модель контракта. HID transport, привязка к адресам MCU, изменение
HEX и прошивальщик отсутствуют. На штатной клавиатуре API пока не доступен.
Библиотека не подключена к desktop workspace и не запускает действий ОС.

## Запуск из корня репозитория

```powershell
cargo test --manifest-path experiments/panel-api/Cargo.toml --target-dir target/panel-api
cargo run --manifest-path experiments/panel-api/Cargo.toml --target-dir target/panel-api --example notification
cargo clippy --manifest-path experiments/panel-api/Cargo.toml --target-dir target/panel-api --all-targets -- -D warnings
```

Пример использует искусственное время: уведомление передаёт цвет, а через 500 мс
без новых кадров управление возвращается штатному эффекту. Устройство не требуется.

Сборка библиотеки для ARM Cortex-M4 без аппаратных операций:

```powershell
rustup target add thumbv7em-none-eabi
cargo build --manifest-path experiments/panel-api/Cargo.toml --target-dir target/panel-api --target thumbv7em-none-eabi --release --lib
```

Результат — `.rlib`, не готовая firmware. Установка target нужна один раз.

## Контракт

- `discover` / `supports_panel`: отличить расширение от штатного эха команды 33.
- `frame_packet`: целый кадр, session token, последовательность и TTL 100–2000 мс.
- `release_packet`: завершить владение; повтор RELEASE допустим.
- `Panel::handle`: проверить пакет и обновить состояние либо передать legacy-пакет
  штатному обработчику (`None`). ACK означает принятие в RAM, не факт физического вывода.
- `Panel::output_frame`: проверить TTL/разрешение и применить штатную яркость.
  `None` означает использовать текущий штатный кадр.
- `Panel::disconnect`: закрыть session при USB reset, disconnect, suspend или переходе
  к диагностике. Эти вызовы должен обеспечить будущий adapter.

Состояние `Panel` занимает 48 байт в проверенной host-сборке. Это не полный расход
RAM вставки: пакеты, стек, обёртки и выравнивание требуют отдельного расчёта на MCU.
Token разграничивает клиентов одного worker, не является механизмом аутентификации.
Помнится последний владелец; долговременная защита от воспроизведения пакетов не заявляется.

Восемь тестов проверяют ложное обнаружение, повреждённые пакеты, TTL, rollover,
владельцев, поздние кадры, повтор RELEASE, яркость и передачу legacy-пакетов.
Аппаратные сроки, ABI и физическая цветопередача ими не проверяются.

## Интеграция

Точный формат пакетов и доказательства по оригинальному ARM-коду —
[контракт firmware](../../docs/firmware/panel-host-api.md).
Границы приложения, следующая работа и критерии готовности —
[модуль lighting-stream](../../modules/lighting-stream.md).

Собственный код прототипа написан по результатам анализа. Исходники OpenAula
не копировались; его подход к малому overlay используется как исследовательский
референс. Распространение производного firmware-образа отдельно не решено.
