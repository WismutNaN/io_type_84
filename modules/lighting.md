# Модуль: подсветка

**Ответственность:** модель сцен, визуальный предпросмотр и выбор доступного способа исполнения. **Расположение:** `crates/io-core/src/lighting/` и редактор `src/features/lighting/`.

## Контекст

У IO прочитаны эффект (16 байт) и 128 RGB-записей по 4 байта. Постоянная запись, временный поток и аппаратная анимация ещё не проверены; ledMaxFrames=0. Наличие анимационных функций в общем сайте не подтверждает их доступность этой модели.

Отдельная физическая LED-панель подтверждена владельцем. Её штатные режимы — переливы и индикация нажатий. Адреса/геометрия/команды пока неизвестны; читать [LED_PANEL](../docs/LED_PANEL.md). Она не сводится к таблице RGB клавиш.

## Публичный интерфейс

| Символ | Тип | Назначение |
|---|---|---|
| LightingScene | aggregate | Версия сцены и её элементы |
| LightingSurface | value object | KeyBacklight / LedPanel со своей геометрией и capabilities |
| KeySelection / Gradient | value object | Область, цвета, направление в физической геометрии |
| AnimationTimeline | value object | Время, интерполяция, повторение |
| LightingOutput | enum | DeviceStatic / DeviceAnimation / HostStream / Unavailable |
| render_scene | функция | Сцена + время + геометрия → цвета физических клавиш |
| compile_device_lighting | функция | Цвета/эффект + capabilities → план применения |

## Зависимости и инварианты

Использует DeviceLayout, CapabilitySet и Clock. Application применяет статические изменения; scheduler адаптера отправляет разрешённые временные кадры.

- Один владелец активного вывода на устройство: preview/сцена/автоматизация согласуют приоритет, не пишут параллельно.
- RGB-адреса не выводятся из порядка элементов Vue.
- 128 RGB-слотов клавиш не определяют адреса LED-панели; связь задаётся проверенным отображением.
- Анимация не использует постоянные SET в цикле, пока не проверено назначение канала и запись в память.
- Очередь кадров ограничена; устаревшие кадры заменяются последним без задержки остановки и обычных операций.
- Ограничения яркости, FPS и размера кадра задаются по модели; качество preview не является подтверждением вывода на железо.

## Намеренно не обрабатывает

Калибровку датчиков, ОС-скрипты, OTA, загрузку чужого исполняемого кода.

## Заметки для реализации

В первом выпуске редактор статического градиента уже полезен без программной анимации. Проверять отображение крайних клавиш и широкого Space, воспроизводимость цвета при одинаковом времени, остановку потока и readback статических цветов. Переключение сцены после выхода помощника требует заранее определённой политики восстановления.
