# Модуль: устройство

**Ответственность:** идентификация устройства, физическая раскладка и доказанные возможности. **Расположение:** `crates/io-core/src/device/`.

## Контекст

Подключён IO Type 84 Magnetic White `0C45:80D6`, firmware 1.17. Его служебные коллекции `FF68:0061` и `FF67:0061`. Настройки читаются через первую. Вторая только открывалась. USB serial пустой. SparkLink/AureTrix не является подтверждённым транспортом этой модели.

## Публичный интерфейс

| Символ | Тип | Назначение |
|---|---|---|
| DeviceIdentity | struct | USB identity, product string, manufacturer/product из ответа, версия |
| DeviceCandidate | struct | Кандидат discovery с идентичностью физического подключения |
| DeviceLayout | struct | PhysicalKeyId → геометрия, DeviceSlot, LedAddress |
| CapabilitySet | struct | Статус, ограничения и доказательство каждой возможности |
| DeviceSession | state machine | Disconnected → Connecting → Identifying → Ready → Recovering |
| DeviceDiscovery / DevicePort | trait | Порты обнаружения и семантических операций |

## Зависимости и инварианты

Зависит только от общих ID/единиц. Конфигурация, подсветка и application читают модель устройства. Дескрипторы и raw handle принадлежат адаптеру.

- 84 физических клавиши не равны 128 позициям протокола. Разреженные адреса не перенумеровываются.
- Статусы чтения, записи и исполнения раздельны. Advertised не становится Verified без испытания.
- HID-путь не вечный ID: после reconnect он может измениться. При неоднозначности нужен выбор.
- Пакеты от предыдущего поколения сеанса не обновляют состояние нового.
- Нельзя объединять MI_02 одного устройства с MI_03 другого только по PID.

## Намеренно не обрабатывает

Формирование пакетов, постоянное хранение профилей, Win32 hooks, выполнение правил.

## Заметки для реализации

Начать с одной проверенной ревизии и диагностического режима для остальных. Не распространять возможности IO White на Pro, Black и беспроводные модели автоматически. Проверить [дескрипторы и снимок](../docs/DEVICE_RESEARCH.md), интерфейсы в [архитектуре](../docs/ARCHITECTURE.md#interfaces). Для тестов использовать неизвестную ревизию, два одинаковых устройства, исчезновение между enumerate/open и изменённую раскладку.
