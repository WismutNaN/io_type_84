# Модуль: прикладные сценарии и профили

**Ответственность:** координация доменных моделей, операций устройства и локального хранения. **Расположение:** `crates/io-core/src/application/`.

## Публичный интерфейс

| Символ | Тип | Назначение |
|---|---|---|
| WorkspaceProfile | document | Конфигурация + сцена + RuleSet + schemaVersion |
| DeviceSnapshot | immutable object | Raw-блоки, декодированное состояние, fingerprint, время |
| Draft | object | Редактируемая версия и ссылки на исходный снимок |
| ChangePlan | value object | Проверенные изменения, требования и порядок |
| ApplyOperation / ApplyReport | state machine/result | Прогресс по блокам, результаты сверки и recovery |
| read_snapshot / validate / apply / recover | use cases | Основные операции приложения |
| ProfileRepository | trait | load/save/list с миграцией и backup |

## Зависимости

Контексты device/configuration/lighting/automation/actions и их порты. Не зависит от реализации hidapi, Win32, Tauri и конкретного формата файловой записи.

## Инварианты

- Локальный профиль, черновик и прочитанное состояние устройства не смешиваются.
- Каждый Apply имеет operationId, fingerprint и предыдущее состояние затронутых блоков.
- Перед SET проверяется актуальность снимка: изменения другим конфигуратором не затираются молча. После проверки всё равно остаётся окно гонки с внешним процессом; абсолютная эксклюзивность не обещается.
- UI не может обходить domain validation передачей raw command.
- Успех части блоков не превращается в общий успех. Нет автоматического rollback без повторного определения устройства и текущего состояния.
- Сохранение JSON не подтверждает применение в клавиатуру; ACK не подтверждает энергонезависимое сохранение.
- Отмена — между безопасными шагами; уже отправленная команда не считается отменённой до выяснения результата.

## Намеренно не обрабатывает

Геометрию Vue, протокол пакетов и низкоуровневую обработку событий Windows.

## Заметки для реализации

JSON-профили небольшие, хранятся в каталоге приложения вне репозитория; импорт требует схемы и миграции. Recovery содержит только необходимые исходные блоки и статусы незавершённого Apply. Это журнал восстановления операции, не event sourcing.

Проверки: disconnect на каждой границе блока; новый snapshot между validate/apply; повреждение JSON; восстановление из backup; неизвестная schemaVersion; частичное подтверждение. См. [ADR хранения](../docs/adr/0002-storage.md).
