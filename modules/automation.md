# Модуль: автоматизация

**Ответственность:** детерминированное распознавание событий и условий с выдачей намерений действий. **Расположение:** `crates/io-core/src/automation/`.

## Контекст

Это программные функции, работающие при запущенном помощнике. Доступность обычного цифрового ввода и его глобальное подавление — разные capabilities. Аналоговая телеметрия IO пока не подтверждена; правила глубины сохраняются как неактивные до проверки канала.

## Публичный интерфейс

| Символ | Тип | Назначение |
|---|---|---|
| RuleSet | aggregate | Версия правил и граф допустимых ссылок |
| Rule | entity | Trigger + Condition + ActionRef + policy |
| SoftwareLayer | entity | Локальный слой с momentary/toggle/приоритетом |
| InputEvent | enum | Down/Up/AnalogSample/ContextChanged/Timer/Disconnected |
| RuleEngine | state machine | Состояние распознавания и детерминированные переходы |
| compile_rules | функция | Проверка неоднозначностей, циклов и возможностей |
| process_event / cancel_session | функции | ActionIntent[] / освобождение runtime-состояния |

## Зависимости

ID устройства/клавиши, Clock, capability requirements и ссылки на каталог Actions. Engine не обращается к HID, Win32, файловой системе и UI. Application включает согласованную версию RuleSet.

## Инварианты

- События одного источника упорядочены и привязаны к поколению сеанса.
- Single/double tap имеет явную политику ожидания; один жест не вызывает оба взаимоисключающих действия случайно.
- Аккорд задаёт одновременность или последовательность, окно времени, отпускание и приоритет конфликтующих правил.
- Autorepeat отличен от повторного физического нажатия. Реинжектированные события не образуют рекурсию.
- Аналоговые пороги имеют гистерезис, единицы и политику устаревания данных. Потеря данных прекращает зависимые действия.
- Смена контекста и RuleSet отменяет или переносит удержание по явно заданной политике; синтетические нажатия имеют учёт владельцев.
- Программные слои не перезаписывают firmware на каждом переключении.

## Намеренно не обрабатывает

Исполнение действий, установку hooks, глобальное подавление клавиш, преобразование хода в силу, гарантии realtime.

## Заметки для реализации

Сначала цифровые триггеры и симулятор. Проверки на виртуальном Clock: границы double tap, отмена при disconnect, два перекрывающихся аккорда, конфликт слоёв, press/release около порога, auto-repeat и остановка при перегрузке. Для аналогового режима отдельный эксперимент должен доказать изменение показаний и их частоту при обычном вводе. [Архитектура runtime](../docs/ARCHITECTURE.md#runtime).
