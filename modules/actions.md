# Модуль: действия и расширения

**Ответственность:** каталог действий компьютера и контролируемое исполнение вызовов.
**Текущий код:** модели в `crates/io-core/src/automation.rs`, отдельный поток
`crates/io-platform/src/action_runtime.rs`. Интерфейсы расширений ниже — проект;
изоляция скриптов отдельным процессом ещё не реализована.

Есть Windows ввод/media/текст/последовательности и фиксированные приложения.
Ближайшее расширение — ProcessAction с выбранной программой, аргументами и рабочим
каталогом; фон и его приёмка описаны в [companion](companion.md). Прошивка для этого
не нужна. Действие и его источник разделены; прошивка не исполняет команды ОС.

## Публичный интерфейс

| Символ | Тип | Назначение |
|---|---|---|
| ActionDefinition | entity | Стабильный ID, версия, параметры, схема, требуемые разрешения |
| Invocation | value object | invocationId, actionId, проверенные параметры, deadline |
| ActionExecutor | trait | invoke и cancel |
| ActionResult | enum | Completed / Failed / Cancelled / TimedOut / Uncertain |
| PermissionGrant | value object | Разрешённые действия и ресурсы конкретного расширения |
| ExtensionManifest | document | Версия API, действия, разрешения, входная точка |

## Зависимости и инварианты

Получает ActionIntent из automation через application. Windows API скрыты адаптером; каталог действий доступен UI для форм.

- На первом этапе только встроенные действия: запуск явно указанного приложения, изменение громкости, затем системные сочетания.
- Shell-строка из Vue не является универсальным IPC. Запуск программы передаёт путь и аргументы раздельно.
- Отмена, ограничение времени и число параллельных запусков обязательны. Повтор после неопределённого результата может дублировать действие и не делается автоматически.
- Синтетические удержания учитывают владельцев: остановка одного правила не отпускает клавишу, ещё нужную другому.
- Скрипты работают в отдельном процессе, с ограничением I/O и объёма ответа. Изоляция процесса сама по себе не является sandbox; реальная модель ограничений выбирается отдельным ADR перед сторонними расширениями.
- Импорт профиля с исполняемым действием не запускает его автоматически. Пользователь видит новые требуемые права.

## Намеренно не обрабатывает

Распознавание жестов, прошивку, каталог публичных расширений, облачный аккаунт.

## Заметки для реализации

В первой фазе помощника не нужен универсальный язык скриптов. Позже оценить WASM с ограниченными host functions либо внешний worker с ограниченным API; выбранную технологию зафиксировать после прототипа отмены и permissions. Проверки: зависание, неверные параметры, неизвестное действие, запрещённый ресурс, аварийное освобождение ввода. Ограничения SendInput описаны в [архитектуре](../docs/ARCHITECTURE.md#runtime).
