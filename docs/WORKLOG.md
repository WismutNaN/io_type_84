## 2026-09-13 — соединение и протокол

**Выполнено:** просмотрены локальные AureTrix и исходное исследование; проверены PnP и HID collections; два vendor HID-интерфейса открыты; статически исследованы HTML и JS официального сайта. Выполнен GET_DEVICE_INFO и затем последовательное чтение блоков настроек временным Python-процессом с hidapi через uv.

**Результат:** IO White `0C45:80D6`, firmware 1.17; рабочий интерфейс FF68:0061, пакеты AA/55. Чтение снимка — 80 пар запрос/ответ с проверкой длины, заголовка, команды, адреса и размера. Проверена карта 84 уникальных физических адресов. Код сайта не исполнялся и в собственный продукт не переносился.

**Ограничение:** SET, сохранение настроек после отключения, analog stream и RGB stream не проверены. Запрос 68 вернул неоднозначные данные. Тестов готового приложения нет, поскольку оно ещё не реализовано. Конфигурация устройства не менялась.

**Артефакты:** [исследование](DEVICE_RESEARCH.md), [протокол](PROTOCOL.md), [снимок](evidence/read-snapshot.json), [метаданные](evidence/device-info.json), [дескрипторы](evidence/hid-descriptors.json), [карта адресов](evidence/layout-reference.json), [источники](evidence/source-manifest.json).

## 2026-09-13 — прошивка, профиль, LED-панель и Vial

**Выполнено:** по каталогу производителя скачан точный HEX White 1.17, написан самостоятельный анализатор Intel HEX без доступа к устройству. Изучен профиль пользователя. Отдельная LED-панель включена в требования и модель световых поверхностей. Проверена гипотеза Vial по сообщению бренда, исходникам GUI и повторному перечислению HID.

**Проверка:** контрольные суммы всех 5677 HEX-записей корректны, 90 728 байт в двух сегментах; шесть тестов анализатора прошли. Профиль содержит 84 клавиши и 128 RT/RGB-записей, но нулевые RT-пороги нельзя считать текущими аппаратными значениями. Найдены семь HID collections и ноль FF60:0061: штатный Vial GUI отфильтрует текущий IO White. Ролик бренда относится к Custom 68. Настройки устройства не изменялись.

**Ограничения:** MCU/OEM и команды панели не доказаны; пробная Thumb-дизассемблировка — признак архитектуры, не восстановленный исходный код. Vial не запускался, его команды не отправлялись. Отсутствие стандартного Vial-интерфейса не исключает частичное QMK-происхождение firmware. Прямое видео не просмотрено; подтверждение модели взято из публикации бренда.

**Артефакты:** [прошивка](FIRMWARE_RESEARCH.md), [профиль](PROFILE_FORMAT.md), [панель](LED_PANEL.md), [Vial](VIAL_RESEARCH.md), [анализатор](../tools/inspect_firmware.py), [HID enumeration](evidence/vial-compatibility.json).

**Контрольная точка:** коммит `research: разобрать White 1.17, профиль, LED-панель и совместимость Vial`.

## 2026-09-13 — Rust/Tauri/Vue каркас

**Выполнено:** созданы workspace core/platform/cli/desktop, Vue shell с навигацией и разделом LED-панели, типизированный IPC app_info, генерация TS из Rust, lockfiles, локальные иконки и команды разработки/упаковки. Макет переведён на явные координаты скриншота владельца: группы F, правый блок, Space, R-Shift и стрелки. Обновлены README, ADR-0001 и руководство разработчика. HID не добавлялся.

**Проверка:** прошли npm run check (Prettier, Vue/TS, Vite, rustfmt, три Rust-теста, Clippy с -D warnings), CLI help/info и неверная команда с кодом 2. Проверены 84 уникальных адреса относительно fixture, границы геометрии, отсутствие пересечений и выравнивание стрелок. Native release EXE собран. В browser preview до уточнения геометрии отображался UI и работал выбор A; окончательная геометрия проверена численно и сборкой.

**Исправление сборки:** начальный debug EXE при выключенном Vite пытался открыть localhost. Явно включён custom-protocol для packaged build, добавлен регрессионный тест наличия HTML/JS/CSS; он прошёл. Библиотека названа io_desktop_lib для устранения предупреждения Windows о совпадающих PDB.

**Ограничение:** повторный осмотр native-окна и фактический ответ Vue → Rust не подтверждены: управление окном остановлено физическим Escape и не возобновлялось. Тест упаковки не объявляется тестом WebView. NSIS, другие ОС, HID, редакторы, импорт профиля и помощник ещё не проверялись/не реализованы. Настройки клавиатуры не менялись.

**Артефакты:** [каркас и команды](DEVELOPMENT.md), [UI](UI.md), [статус](STATUS.md), `target/release/io-desktop.exe` (локальная сборка, не в Git).

**Контрольная точка:** коммит `feat: собрать каркас Rust Tauri Vue с макетом IO Type 84`.
