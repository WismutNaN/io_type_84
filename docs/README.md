# Документация IO Type 84

Приложение предназначено сначала для личного использования владельцем IO Type 84 Magnetic. Оно объединяет редактор настроек клавиатуры и фоновый помощник для действий на компьютере. Настройки, выполняемые прошивкой, и сценарии, требующие приложения, явно различаются в интерфейсе.

## Как читать

Для продолжения начать с [текущего состояния](STATUS.md) и [единой карты возможностей](INTEGRATION.md).
Она разделяет штатную настройку, фон без перепрошивки и расширение устройства,
связывает цели с доказательствами. Затем выбрать фазу и нужный модуль. История и
подробные исследования сохраняются в своих документах; весь архив читать не нужно.

## Маршруты чтения по задачам

| Задача               | Минимальный контекст                                        |
| -------------------- | ----------------------------------------------------------- |
| Выбрать глубину интеграции | STATUS → INTEGRATION → ADR-0007 |
| Довести фоновую работу | STATUS → PLAN фаза 10 → modules/companion → modules/action-catalog |
| Подключение и codec  | STATUS → PROTOCOL → modules/adapters → fixtures             |
| Панель              | STATUS → LED_PANEL → firmware-lighting-v1.17 → modules/lighting |
| Firmware / recovery | STATUS → INTEGRATION раздел C → firmware/README → нужный документ; основа OpenAula |
| Импорт профиля сайта | STATUS → PROFILE_FORMAT → modules/application               |
| Модель настроек      | STATUS → modules/configuration → capabilities в архитектуре |
| UI                   | STATUS → UI → нужный feature-модуль и IPC-контракты         |
| Правила              | STATUS → modules/automation → runtime в архитектуре         |
| Действия ОС          | STATUS → modules/actions → ADR-0004                         |
| Обновить архитектуру | DECISIONS → соответствующий ADR → затронутые модули/фазы    |

В ADR фиксируется причина решения, в WORKLOG — факт выполнения. STATUS содержит только актуальное состояние, а не историю обсуждения.

Редизайн и программная глубина: [UI](UI.md) → [модуль editor-interaction](../modules/editor-interaction.md) → [ADR-0005](adr/0005-editor-interaction.md). Это краткий маршрут для агента, работающего только с интерфейсом или обработкой нажатий.

Каталог/жесты: [реализованные контракты](../modules/action-catalog.md) → [ADR-0006](adr/0006-actions-gestures-scenes.md). Уведомления, скрипты, LLM и сцены описаны как расширения, не готовые интеграции.

Подсветка в бинарнике: [White 1.17 — RGB и полоса](firmware-lighting-v1.17.md) → [воспроизводимый отчёт](evidence/firmware-lighting-analysis.json).
