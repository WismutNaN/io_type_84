# Интерфейс

Цель — настраивать выбранные клавиши на одной схеме, видеть место исполнения функции и не терять исходные настройки. Базовая версия повторяет полезные возможности сайта для реальной модели, а не все страницы общего bundle.

## Главный экран

```text
[IO Type 84 White • подключена] [Профиль: Работа ▾] [Сохранить]
[Назначения] [Ход / RT] [Подсветка] [Макросы] [Правила]

[Основной / Fn / программный слой]    [Отмена] [Применить: 3 изменения]

┌──────────────────────────┬──────────────────────────────┐
│ Схема 84 клавиш          │ Параметры выбранных клавиш   │
│ Выделение / цвета / ход  │ Значения и ошибки           │
│                         │ Выполняется: в клавиатуре   │
└──────────────────────────┴──────────────────────────────┘
[Помощник: остановлен] [Операция / результат] [Диагностика]
```

Всегда видны устройство, профиль, выбранный слой, черновые изменения и состояние помощника. Служебные адреса, raw-пакеты и хеши доступны в диагностике, а не в обычном редакторе.

## Сценарии

| Сценарий | Действия | Цель |
|---|---|---|
| Изменить назначение | Выбрать клавишу → выбрать действие → применить | 3 действия после открытия раздела |
| Изменить RT группы | Выделить клавиши → отредактировать параметры → применить | Один общий редактор, mixed values сохраняются |
| Статический градиент | Выделить группу → задать цвета/направление → применить | Preview на схеме до записи |
| Сменить профиль | Выбрать профиль → увидеть изменения → применить | 3 действия; несохранённый черновик не теряется |
| Создать правило | Выбрать клавишу → триггер/условия/действие → проверить и включить | Сложный сценарий может требовать больше 3 действий |

Клик по клавише выбирает её, Ctrl/Shift расширяют выделение, рамка выбирает группу. Для разнородных значений показывается «Разные», а неизменённые параметры не обнуляются. Поиск действий содержит понятные названия и обозначение аппаратного/программного исполнения.

## Применение и сохранение

«Сохранить профиль» сохраняет локальный документ. «Применить к клавиатуре» меняет устройство. «Включить правила» активирует помощник. Эти состояния не объединяются в одну неясную кнопку.

В компактном просмотре изменений: какие клавиши/блоки затронуты, новые значения, требуется ли работа помощника. После записи показать «Проверено чтением»; сохранение после отключения отображать отдельно, когда оно проверено. При частичном применении показать успешные и неизвестные части и действие «Перечитать устройство».

## Правила и слои

Первая версия редактора правил — форма «Когда → При условиях → Выполнить», без обязательного графового полотна. У single/double tap сразу видно, ждёт ли одиночное действие второе нажатие. У аккорда — порядок и временное окно. У глубины — единицы мм, пороги и гистерезис. Недоступная телеметрия оставляет правило сохранённым, но не активным.

Аппаратный Fn и программные слои разделены подписью. При выключенном помощнике видно, какие функции перестанут выполняться. Профиль по активному приложению меняет runtime в памяти; он не должен бесконтрольно перезаписывать клавиатуру при каждом переключении окна.

## Подсветка

Схема использует физические координаты клавиш, а не плотную таблицу адресов. Цветовые сцены содержат области, палитру и направление. У анимации отдельно показаны предпросмотр, запуск на компьютере и сохранение в клавиатуру, если оно поддержано. Отсутствие канала не выдаётся за чёрную клавиатуру или успешное применение.

## Состояния

| Состояние | Представление |
|---|---|
| Нет устройства | Подключение USB и список кандидатов; локальные профили доступны |
| Несколько устройств | Выбор с продуктом и физическим подключением |
| Неизвестная ревизия | Доступна диагностика, запись недоступна с конкретной причиной |
| Чтение | Прогресс блоков; редактирование ещё не загруженных данных запрещено |
| Черновик | Количество изменений, undo/redo, исходное значение поля |
| Запись | Прогресс и отмена между безопасными шагами |
| Ошибка/отключение | Сохранённый черновик, состояние применения, повторное чтение |
| Возможность не подтверждена | Объяснение и ссылка на локальную диагностику |
| Помощник остановлен | Явный статус рядом с программными правилами |

Горячие клавиши: Ctrl+S — сохранить профиль; Ctrl+Z/Ctrl+Shift+Z — undo/redo черновика; Esc — снять выделение или закрыть редактор. Комбинацию аварийной остановки помощника выбрать и проверить при его реализации; она не должна зависеть от активного RuleSet. Действие остановки всегда доступно в tray.
