# Прошивка IO White: база для продолжения

Обновлено: 2026-09-14. Область доказательств — официальный HEX White 1.17,
загрузчик IO Vision, SDK Sonix и зафиксированная ревизия OpenAula. На этом этапе
устройство не прошивалось, в ISP не переводилось, flash с него не считывалась.

**Основой дальнейшей работы выбраны OpenAula и официальный Sonix DFP.**
OpenAula даёт реализованные расширения штатной прошивки и исследование родственной
AULA Mini 60 HE Pro. DFP даёт определения MCU и периферии. Собственный анализ IO
нужен для проверки различий платы, адресов, сохранности данных и восстановления.
Новый драйвер датчиков и полноценную прошивку с нуля сейчас не разрабатываем.
[Сравнение и конкретные компоненты для повторного использования](../reference-projects/OPENAULA.md).

## Что установлено

| Результат | Основание | Граница вывода |
|---|---|---|
| Семейство SN34F280, Cortex-M4F | Совпадение startup, карты MMIO, таблицы IRQ и USER_MODE_FLAG с официальным DFP | Точная маркировка установленного MCU и ревизия PCB ещё не прочитаны |
| USER ROM 504 КиБ; SDK описывает SRAM 160 КиБ | PDSC, SVD, алгоритм flash и размер буфера WASM | Это характеристики семейства; свободная RAM в работающем IO не измерена |
| White использует Sonix ISP из WASM | Ветка `isHex` сайта и совпадающая Feature-report magic в HEX | Интерфейс/identity загрузчика реального IO ещё не проверены |
| Загрузчик готовит весь USER ROM с нулевыми пропусками | Изолированное исполнение только HEX-loader, независимое сравнение | Это образ обновления, не backup установленной flash |
| Калибровка хранится в USER ROM | Таблицы `0x8400/0x8500`, вызовы записи при завершении калибровки | Индивидуальные значения клавиатуры не сохранены |
| Собственные слои и RGB-эффекты возможны на родственной AULA | Исходники OpenAula overlay | Готового переноса на IO и управления его полосой нет |

Получен читаемый локальный атлас **436 кандидатов функций** с ассемблером и
псевдокодом. Он помогает восстанавливать логику, но не заменяет оригинальный
исходный код, не компилируется обратно в штатный образ и не содержит Boot ROM.

## Чего пока нет

Нет полного backup конкретного устройства, дампа Boot ROM, снимка Code Option/SM,
проверенного аппаратного входа в восстановление, принятого downgrade и безопасного
прошивальщика IO. Наличие официального HEX и работающего flasher для AULA этих
пробелов не закрывает. Текущий desktop остаётся конфигуратором и программным
помощником; кнопки «прошить» или неявного ISP при подключении нет.
