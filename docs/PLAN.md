# План реализации

Стек: Rust + Tauri 2 + TypeScript + Vue 3. Первая платформа: **Windows + USB, подтверждено пользователем**. Проект открытый; платформенные адаптеры должны позволять добавление других ОС. Фазы ниже — проект последовательности, не выполненные работы. Каждая оставляет запускаемую систему. Размер фазы ориентировочно 1–5 рабочих дней одного разработчика; при превышении объёма фазу разделить до начала реализации, не скрывать незавершённость.

Обновление 2026-09-14: native open/GET и SET/readback/restore основных блоков подтверждены. Vue-редакторы реализованы. FB получен, полный физический тест остаётся; RGB streaming не проверен. Актуальная матрица — [EDITOR_IMPLEMENTATION](EDITOR_IMPLEMENTATION.md). Незавершённые проверки ниже не становятся выполненными от наличия формы. Свидетельства — [DEVICE_RESEARCH](DEVICE_RESEARCH.md). Для каждой фазы читать указанные модули и её контекст.

**Контекст для агента:** завершены выбранные ветви возможностей; отрицательные результаты analog/RGB допустимы при честном UI. Реализация Linux/macOS в эту фазу не включена, но зависимости core проверяются.

## Миграция UI/UX — 2026-09-14

**Исходное состояние:** крупные вводные блоки, один светлый язык/стиль, инспектор уходит ниже экрана, selection и движение конкурируют.
**Цель:** видимая схема и доступный редактор, визуальные условия, локализация и расширяемый каталог действий.
**Стратегия:** последовательно, сохраняя существующие backend-операции и JSON v1.

- [x] Базовые TS/Rust проверки; регрессии старения кадра и потерянного release. Откат: `6c80e7e` содержит отдельное исправление без редизайна.
- [x] Общие UI tokens, темы, язык, широкая/узкая компоновка, DKS по этапам → [UI](UI.md), [editor-interaction](../modules/editor-interaction.md).
- [x] Чистая модель глубины и Windows adapter; нет автоматического включения → [editor-interaction](../modules/editor-interaction.md), [ADR-0005](adr/0005-editor-interaction.md).
- [x] Автоматическая проверка интерфейса и native GET/monitor. Физические глубокие PgUp/PgDn остаются незавершённой аппаратной приёмкой.
- [ ] Следующий этап: сохранение незавершённых форм, mixed values групп, составной профиль с правилами и сценами; затем условия приложения/слоёв и общий каталог → [UI — расширение](UI.md#расширение-ux), [application](../modules/application.md).

**Rollback:** коммит редактора атомарен относительно DTO и Rust/runtime. Возврат к `6c80e7e` возвращает прежний UI с исправленным TTL; JSON v1 устройства совместим, дополнительные `io.locale/io.theme/io.rules.v1` игнорируются старой версией. Не использовать выборочный откат DTO отдельно от consumer.

## Каталог, жесты и события — продолжение

**Готово в коде:** каталог действий/варианты ОС, условия по глубине и удержанию группы, общий черновик и profile v2, Windows queue adapter. Контекст: [action-catalog](../modules/action-catalog.md).

**Приёмка:** физический полный ход PgUp/PgDn и одновременных клавиш; непрерывность удержания при simulation; foreground/minimized поведение.

**Следующий этап:** ScriptCatalog и провайдеры действий с типизированными входами/выходами; графы последовательностей для LLM и внешних сервисов; отдельная UI-страница автоматизации. Источники событий Telegram/почта, LightScene для набора клавиш и LED-панели, композиция приоритетов/TTL/снятия непрочитанного, локальный preview. USB-вывод сцены только после подтверждения временного RGB и выхода из него. [ADR-0006](adr/0006-actions-gestures-scenes.md). Не добавлять все формы в инспектор клавиши.
