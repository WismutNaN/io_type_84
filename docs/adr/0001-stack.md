# ADR-0001: стек и границы приложения

**Дата:** 2026-09-13. **Статус:** стек и Windows + USB подтверждены пользователем; устройство модулей предложено.

## Контекст

Пользователь выбрал Rust + Tauri + TypeScript + Vue и открытое распространение. Сначала нужен конфигуратор Windows для USB, с возможностью добавить другие ОС. Реальное устройство успешно отвечает через native HID.

## Рассматриваемые варианты

1. Обернуть AureTrix в desktop shell — быстрый пример UI, но SparkLink-транспорт не соответствует устройству.
2. Новый модульный Tauri-проект с Rust-протоколом IO — требует реализации codec, даёт общий фундамент конфигуратора и помощника.

## Решение

Выбрана новая основа: Tauri 2, Vue 3, TypeScript, Rust-core и платформенные адаптеры. AureTrix — референс UX и отдельных компонентов с сохранением происхождения при переносе. Не зависеть от WebHID в WebView. DDD применяется к моделям и границам, без микросервисов и обязательного crate на каждую сущность.

Поддержка других ОС закладывается портами HID/input/actions/storage. Расширение не обещает одинаковые разрешения, подавление ввода или инъекцию событий на всех платформах. Core и редакторы должны быть переносимы, каждое системное действие получает платформенный capability.

Для собственного кода предложена MIT; окончательный текст лицензии и список уведомлений выбрать до первой публикации. HallJoy не включается в зависимости; сторонний код сайта не переносится в репозиторий продукта. Открытость проекта не означает автоматическую совместимость любых лицензий.

## Последствия

Проще повторно использовать домен и CLI. Сложнее начальная реализация протокола, но она уже опирается на реальные ответы. Закрывается путь к непосредственному использованию SparkLink SDK как основной реализации IO без новых доказательств совместимости.
