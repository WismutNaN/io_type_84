# Текущее состояние

Обновлено: 2026-09-14. Точка входа для продолжения работы. [История](WORKLOG.md), [решения](DECISIONS.md), [покрытие редактора](EDITOR_IMPLEMENTATION.md).

## Работает

- Windows EXE на Rust + Tauri + TS + Vue. Проверен настоящий WebView: подключение через UI прочитало IO White `0C45:80D6`, firmware `1.17`; Vite не является источником ресурсов release-сборки.
- Native HID: точная identity/descriptor, AA/55, GET-снимок, один worker и ограниченная очередь. 84 физических клавиши отделены от 128 слотов. CLI `snapshot`, `colors`, `monitor N`; произвольных SET/OTA в CLI нет.
- Редакторы: базовый/Fn слой, обычные/медиа/мышь/сочетания/действия прошивки, RT, аппаратные эффекты, цвета и градиенты, макросы, MT/TGL/RS/SOCD/DKS, частота и мёртвые зоны.
- Общая схема клавиатуры, выбор группы/поиск, черновик, групповая отмена/возврат, проверка перед применением. Сохранение локального профиля отдельно от записи в устройство; импорт/экспорт собственной схемы и частичный импорт IO Vision с отчётом.
- Перед SET: проверка ревизии, полный резервный raw-снимок в пользовательском каталоге, flush. После каждого изменённого блока: побайтный GET-readback. Есть подготовка восстановления последней операции.
- Получен FB-поток: UI показывает свежий ход по адресам, возраст данных, последние 20 начал движения с пиком. История только в памяти; stop при закрытии окна, watchdog 5 с при пропаже UI polling.

## UI/UX, 2026-09-14

Рабочая адаптивная компоновка: справа от клавиатуры при ≥1280 px, снизу в меньшем окне. RU/EN, light/dark/system, общие шкалы, подписи назначений, LED под Del/PgDn. Выбор и физическое движение независимы. Зависший IPC больше не удерживает подсветку: кадр стареет на клиенте, TTL 600 мс. DKS редактируется через четыре этапа. Компьютерные действия хранятся отдельно от аппаратных профилей и требуют явного включения.

Минимальный контекст: [UI](UI.md) → [editor-interaction](../modules/editor-interaction.md) → [ADR-0005](adr/0005-editor-interaction.md). Проверки: `npm run check`, `npm run test:ui`, `npm run desktop:build`; подробное свидетельство в `evidence/ui-redesign.json`.

## Аппаратные доказательства

1. Native snapshot и 20 секунд simulation: 19 833 пакета, два адреса, максимум 0,18 мм; конфигурация не изменилась. [Данные](evidence/native-rust-initial.json).
2. Яркость `5 → 4 → 5` с совпавшим readback. Первый эксперимент выявил FF/AA/55 как write-only маркеры; codec исправлен, исходный снимок восстановлен.
3. Один обратимый эксперимент: F12→F11, Fn+F12→F10, RT F12 1,20/0,10/0,20 мм, RGB F12, свободные макрос/DKS без назначения. Все шесть блоков приняты и прочитаны обратно; восстановлены также затронутые свободные байты макрообласти. Итоговая ревизия равна исходной. [Данные](evidence/native-write-roundtrip.json).

Это подтверждает протокол хранения. Физическое исполнение remap/RT/макросов/advanced и сохранение после снятия питания ещё не проверены. SET общих параметров реализован, аппаратный тест частоты/мёртвых зон не проводился. Калибровка/reset/OTA не запускались.

## Открытые ограничения

- Полное соответствие FB адресов физическим клавишам, полный ход и отпускание ещё требуют совместного теста. В наблюдении приходили только два адреса (`;` и `'` по текущей карте), по 0,18 мм, включая повторные события. История использует фильтр 0,30/0,15 мм; сырая глубина остаётся доступна на шкале; её нельзя выдавать за точный HID key-down или силу в ньютонах.
- GET `33` вернул эхо запроса. Текущий RGB неизвестен; UI отличает его от заданных цветов и не подставляет нули как измерение. Временный RGB `32` и анимации с компьютера не реализованы.
- LED-панель отдельная. В профиле найдены штатные Fn+G (`FUNC 87`, глубина RT), Fn+K (`91`, наложение), Fn+L (`27`, эффект полосы). Их можно переназначать как firmware actions; физическое исполнение не проверялось. Прямые параметры/топология панели неизвестны, GET `1B` ранее дал timeout. [Контекст](LED_PANEL.md).
- Макросы ограничены 512 байтами вместе с каталогом; реальная полезная ёмкость ещё неизвестна. Импорт сайта не переносит его каталоги макросов/DKS и непроверенные функции; собственный JSON переносит их. Неизвестный формат имеющегося макроса блокирует его перезапись.
- Есть ограниченный runtime глубины → четыре media-действия Windows при открытом приложении и мониторинге. Физическое выполнение PgUp/PgDn/громкости ещё не принято; есть тесты модели и интерфейса. Нет tray, общего runtime правил, скриптов, программных слоёв, глобальных hooks, аудиореактивного света, редактора анимаций, калибровки и прошивальщика. Установщик NSIS и другие ОС не проверены. Полный паритет сайта не заявляется.

## Следующая работа

Совместная физическая проверка FB: по одной A/S/D, медленное нажатие, удержание, отпускание, две одновременно; сопоставить адрес/ADC/ход и шум. Затем тест выполнения обычного remap, RT и короткого макроса в контролируемом поле ввода, далее отдельные advanced режимы. Проверка после отключения питания — отдельная операция.

Для продолжения достаточно [руководства разработчика](DEVELOPMENT.md), [покрытия функций](EDITOR_IMPLEMENTATION.md) и нужного модуля. Для HID — [протокол](PROTOCOL.md); для панели — [LED_PANEL](LED_PANEL.md); для импорта — [PROFILE_FORMAT](PROFILE_FORMAT.md). Полные bundles, конфигурации и backup — в игнорируемом `archive_data/` либо app data. Не читать весь архив.

Контрольные точки: `40e8e4e` native чтение; `6886b8e` проверяемая запись/recovery; последующий коммит Vue-редакторов указан в [WORKLOG](WORKLOG.md). Rust 1.96.0, Node 26.3.0, VS Build Tools 2022, WebView2 150 проверены в этой среде.

### Состояние сборки после редизайна

Исходники, frontend build и 3 UI-теста актуальны и проходят. Первый новый native EXE проверен через GET/monitor. Финальная замена EXE не выполнена: Windows удерживает запущенный `target/release/io-desktop.exe`; затем пользователь остановил Computer Use клавишей Escape. После закрытия окна выполнить `npm run desktop:build`. Последние изменения коротких подписей и свёрнутой формы есть в коде, но ещё не в открытом EXE. [Свидетельство](evidence/ui-redesign.json).
