# Текущее состояние

Обновлено: 2026-09-13. Этот файл — краткая точка входа для следующего участника/агента. История отдельно в [WORKLOG](WORKLOG.md), решения — в [DECISIONS](DECISIONS.md).

## Готово и проверено

- Обнаружен реальный IO Type 84 Magnetic White, USB `0C45:80D6`, версия по протоколу `1.17`.
- Открыты служебные HID-интерфейсы `FF68:0061` и `FF67:0061`. Обмен проверен на первом.
- Native hidapi прочитал информацию, общие настройки, основной/Fn keymap, RT, эффект/RGB, DKS и каталог макросов. Последовательный снимок содержит 80 валидированных ответов.
- Найдено точное описание модели и формат протокола в статическом коде официального сайта. Подготовлена карта 84 физических клавиш к разреженным адресам из 128 слотов.
- Подготовлены архитектура, модули, UI-концепция, фазы и предложенные ADR.

## Не реализовано / не доказано

Приложения Rust/Tauri/Vue и постоянного диагностического CLI ещё нет. Запись, физическое исполнение новых назначений и сохранение после отключения не проверены. Analog GET дал неоднозначный ответ; stream не подтверждён. Программная RGB-анимация и аппаратное сохранение анимаций не проверены. Не заявлять полный паритет сайта.

Настройки клавиатуры в этом исследовании не изменялись. Калибровка, simulation mode, reset и OTA не запускались. HID handles закрыты.

## Подтверждённые ограничения проекта

Rust + Tauri + TS + Vue; Windows + проводное USB сначала; архитектура переносится на другие ОС через adapters; проект открытый. Корневой README предназначен для GitHub, рабочие сведения размещаются здесь. Проверенные результаты фиксируются отдельными коммитами.
