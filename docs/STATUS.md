# Текущее состояние

Обновлено: 2026-09-14. Точка входа для продолжения работы. [История](WORKLOG.md), [решения](DECISIONS.md), [покрытие редактора](EDITOR_IMPLEMENTATION.md).

## Работает

- Windows EXE на Rust + Tauri + TS + Vue. Проверен настоящий WebView: подключение через UI прочитало IO White `0C45:80D6`, firmware `1.17`; Vite не является источником ресурсов release-сборки.
- Native HID: точная identity/descriptor, AA/55, GET-снимок, один worker и ограниченная очередь. 84 физических клавиши отделены от 128 слотов. CLI `snapshot`, `colors`, `monitor N`; произвольных SET/OTA в CLI нет.
- Редакторы: базовый/Fn слой, обычные/медиа/мышь/сочетания/действия прошивки, RT, аппаратные эффекты, цвета и градиенты, макросы, MT/TGL/RS/SOCD/DKS, частота и мёртвые зоны.
- Общая схема клавиатуры, выбор группы/поиск, черновик, групповая отмена/возврат, проверка перед применением. Сохранение локального профиля отдельно от записи в устройство; импорт/экспорт собственной схемы и частичный импорт IO Vision с отчётом.
- Перед SET: проверка ревизии, полный резервный raw-снимок в пользовательском каталоге, flush. После каждого изменённого блока: побайтный GET-readback. Есть подготовка восстановления последней операции.
- Получен FB-поток: UI показывает свежий ход по адресам, возраст данных, последние начала движения с пиком; видимая строка без scrollbar, хранение не больше трёх её ширин. История только в памяти; stop при закрытии окна, watchdog 5 с при пропаже UI polling.

## UI/UX, 2026-09-14

Рабочая адаптивная компоновка: справа от клавиатуры при ≥1280 px, снизу в меньшем окне. RU/EN, light/dark/system, общие шкалы, подписи назначений, LED под Del/PgDn. Выбор и физическое движение независимы. Зависший IPC больше не удерживает подсветку: кадр стареет на клиенте, TTL 600 мс. DKS редактируется через четыре этапа. Каталог действий и жесты входят в общий черновик, undo/redo и профиль v2. Исполнение включается при применении либо отдельным переключателем; импорт и сохранение профиля ничего не запускают. Свет имеет локальный анимированный предпросмотр, обе страницы используют одинаковую адаптивную компоновку. Есть явное снятие выделения.

Минимальный контекст: [UI](UI.md) → [editor-interaction](../modules/editor-interaction.md) → [каталог действий](../modules/action-catalog.md) → [ADR-0006](adr/0006-actions-gestures-scenes.md). Проверки: `npm run check`, `npm run test:ui`, `npm run desktop:build`; подробное свидетельство в `evidence/ui-redesign.json`.

## Аппаратные доказательства

1. Native snapshot и 20 секунд simulation: 19 833 пакета, два адреса, максимум 0,18 мм; конфигурация не изменилась. [Данные](evidence/native-rust-initial.json).
2. Яркость `5 → 4 → 5` с совпавшим readback. Первый эксперимент выявил FF/AA/55 как write-only маркеры; codec исправлен, исходный снимок восстановлен.
3. Один обратимый эксперимент: F12→F11, Fn+F12→F10, RT F12 1,20/0,10/0,20 мм, RGB F12, свободные макрос/DKS без назначения. Все шесть блоков приняты и прочитаны обратно; восстановлены также затронутые свободные байты макрообласти. Итоговая ревизия равна исходной. [Данные](evidence/native-write-roundtrip.json).

Это подтверждает протокол хранения. Физическое исполнение remap/RT/макросов/advanced и сохранение после снятия питания ещё не проверены. SET общих параметров реализован, аппаратный тест частоты/мёртвых зон не проводился. Калибровка/reset/OTA не запускались.

## Открытые ограничения

- Полное соответствие FB адресов физическим клавишам, полный ход и отпускание ещё требуют совместного теста. В наблюдении приходили только два адреса (`;` и `'` по текущей карте), по 0,18 мм, включая повторные события. История использует фильтр 0,30/0,15 мм; сырая глубина остаётся доступна на шкале; её нельзя выдавать за точный HID key-down или силу в ньютонах.
- GET `33` вернул эхо запроса. Текущий RGB неизвестен; UI отличает его от заданных цветов. У `32` найдены запись RAM и таймер возврата (50 периодов по 2000 вызовов scheduler); реальное время и аппаратная обратимость не измерены. Анимации с компьютера на устройстве не реализованы. [Разбор firmware](firmware-lighting-v1.17.md).
- LED-панель отдельная. В профиле найдены штатные Fn+G (`FUNC 87`, глубина RT), Fn+K (`91`, наложение), Fn+L (`27`, эффект полосы). Их можно переназначать как firmware actions; физическое исполнение не проверялось. В HEX восстановлены десять логических позиций 84…93 и внутренний renderer глубины; геометрия и прямой host setter не проверены. GET `1B` отсутствует в найденном dispatcher. [Контекст](LED_PANEL.md).
- Аппаратные макросы ограничены 512 байтами вместе с каталогом; реальная полезная ёмкость ещё неизвестна. Импорт сайта не переносит его каталоги макросов/DKS и непроверенные функции; собственный JSON переносит их. Неизвестный формат имеющегося макроса блокирует его перезапись.
- Есть GestureEngine для глубины/удержания 1–8 физических клавиш и отдельный Windows worker: сочетания, media, текст, последовательности, Word/Notepad/Calculator. Каталог хранит варианты Windows/Linux/macOS; исполняется только Windows. Несколько порогов независимы, исходный ввод не подавляется. Физическое выполнение PgUp/PgDn/громкости ещё не принято; есть тесты модели и интерфейса. Нет tray, double tap/взаимоисключающих порогов, скриптов, программных слоёв, глобальных hooks, аудиореактивного света, редактора анимаций, калибровки и прошивальщика. Установщик NSIS и другие ОС не проверены. Полный паритет сайта не заявляется.

## Firmware: новый результат 2026-09-14

[Краткая база](firmware/README.md) → только нужная часть: MCU, калибровка,
ISP/recovery, OpenAula или воспроизведение. В этом этапе железо не опрашивалось.

- Официальный Sonix DFP указывает SN34F280, Cortex-M4F, USER ROM 504 КиБ, SRAM
  160 КиБ. Startup/MMIO/IRQ/boot flag совпадают с IO. Точный корпус/маркировка ещё
  неизвестны; утверждение Cortex-M3/32 КиБ из OpenAula не принимаем.
- Готов локальный читаемый атлас 436 кандидатов функций. Это псевдокод и
  ассемблер, не оригинальный собираемый проект и не дамп Boot ROM.
- Изолированный штатный HEX-loader с запрещёнными host imports выдал полный
  504-КиБ payload с нулевыми пропусками и defaults калибровки. Независимое сравнение
  хеша/длины/суммы прошло. 15 Python-тестов прошли без пропусков.
- `65` завершает калибровку **с записью flash**; max/min находятся в `0x8400/0x8500`.
  Индивидуальных таблиц устройства, полного USER ROM и Code Option/SM backup нет.
- OpenAula содержит готовые overlay/слои/анимацию клавиш. Перенос IO не реализован;
  flasher AULA даже в dry run отправляет Code Option, поэтому не запускался.
- Полный recovery и downgrade не проверены. Приложение и firmware устройства
  этим исследованием не изменены. Инструменты/свидетельства: коммит `e55c11c`.
