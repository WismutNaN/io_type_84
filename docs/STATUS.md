# Текущее состояние

Обновлено: 2026-09-13. Этот файл — краткая точка входа для следующего участника/агента. История отдельно в [WORKLOG](WORKLOG.md), решения — в [DECISIONS](DECISIONS.md).

## Готово и проверено

- Обнаружен реальный IO Type 84 Magnetic White, USB `0C45:80D6`, версия по протоколу `1.17`.
- Открыты служебные HID-интерфейсы `FF68:0061` и `FF67:0061`. Обмен проверен на первом.
- Native hidapi прочитал информацию, общие настройки, основной/Fn keymap, RT, эффект/RGB, DKS и каталог макросов. Последовательный снимок содержит 80 валидированных ответов.
- Найдено точное описание модели и формат протокола в статическом коде официального сайта. Подготовлена карта 84 физических клавиш к разреженным адресам из 128 слотов.
- Подготовлены архитектура, модули, UI-концепция, фазы и предложенные ADR.
- Созданы Rust workspace (core/platform/cli), Tauri 2 composition root и Vue/TS shell. README содержит команды запуска; [устройство каркаса](DEVELOPMENT.md).
- Vue показывает обзор с выбором одной клавиши, отдельную LED-панель и страницы будущих редакторов. Геометрия 84 клавиш исправлена по скриншоту владельца, слоты совпадают с референсом; пересечений клавиш нет, стрелки выровнены.
- `npm run check` прошёл: формат, TypeScript/Vite, rustfmt, три Rust-теста (два контракта и упаковка HTML/JS/CSS), Clippy с запретом предупреждений. CLI help/info и ошибка неизвестной команды с кодом 2 проверены.
- Release Windows EXE собирается с `custom-protocol`; конфигурация включает локальные ресурсы. Начальный browser preview проверен, клик A менял выделение; после уточнения геометрии выполнены проверки координат и сборка.
- HEX White 1.17 скачан и проверен собственным анализатором: 5677 корректных записей, 90 728 байт данных. Шесть Python-тестов прошли. [Прошивка](FIRMWARE_RESEARCH.md), [профиль](PROFILE_FORMAT.md), [панель](LED_PANEL.md).
- Vial проверен по исходникам и текущему HID enumeration: семь collections, ни одной FF60:0061. Штатное обнаружение Vial не подходит White в этом режиме. Ролик IO относится к Custom 68; [подробности](VIAL_RESEARCH.md).

## Не реализовано / не доказано

HID-транспорт на Rust, импорт профилей, реальные редакторы, runtime и запись ещё не реализованы. Подтверждённое ранее native чтение выполнялось исследовательским Python-процессом. Analog GET дал неоднозначный ответ; stream не подтверждён. Команды/геометрия LED-панели, RGB streaming, точный MCU/OEM и происхождение прошивки не установлены. Не заявлять полный паритет сайта или физическое измерение силы.

Повторная ручная проверка автономного EXE и Vue → Rust **не завершена**. При первом запуске debug EXE обнаружен запрос к выключенному dev-серверу. В скриптах явно закреплён custom-protocol, тест включения ресурсов прошёл и release пересобран. Управление окном было остановлено физическим Escape; после этого UI-автоматизация не продолжалась. Установщик NSIS и другие ОС не проверены.

Настройки клавиатуры в этом исследовании не изменялись. Калибровка, simulation mode, reset и OTA не запускались. HID handles закрыты.

## Подтверждённые ограничения проекта

Rust + Tauri + TS + Vue; Windows + проводное USB сначала; архитектура переносится на другие ОС через adapters; проект открытый. Корневой README предназначен для GitHub, рабочие сведения размещаются здесь. Проверенные результаты фиксируются отдельными коммитами.
